<Update label="1.6.1">
  ## Organization Two-factor Authentication Requirement

* The Customer object now returns `customer_requires_two_factor_authentication` (boolean). It is `true` when the organization requires two-factor authentication from every member.
</Update>

<Update label="1.6.0">
  ## Organization Accounts

* The Customer object now describes the account, not an individual user. It returns `customer_type` (`personal` or `organization`), `user_id_owner`, `customer_organization_name`, `customer_organization_legal_id`, `customer_domain`, `customer_billing_tax_id`, and `customer_billing_tax_id_type`.

* The Customer object no longer returns personal user fields: `customer_email_address`, `customer_first_name`, `customer_last_name`, `customer_billing_name`, `customer_phone_number`, `customer_dob`, `customer_profile_image_url`, `customer_iso_language_code`, `customer_last_login_datetime`, `customer_discord_id`, `customer_discord_oauth_id`, `customer_google_oauth_id`, `customer_email_two_factor_authentication`, and `customer_requires_password_change`.
</Update>

<Update label="1.5.99">
  ## List proxies with the OS parameter and retrieve active node counts

* Residential & Mobile list endpoints now accept an list_os parameter within the options of windows, linux, and android.

* A generated Residential or Mobile proxy with an OS target will utilize a proxy node with that Operating System.

* The same node counts you are used to with geo-located proxies are available for OS parameter selection.
</Update>

<Update label="1.5.95">
  ## Filter Proxies by Availability

* Proxy search now accepts a `proxy_is_online` parameter. Pass `proxy_is_online=true` to return only proxies whose subnet is currently online, so proxies affected by an ongoing network incident are left out of your list.

* `proxy_is_online=false` returns only the affected proxies, and omitting the parameter returns all proxies as before.
</Update>

<Update label="1.5.90">
  ## Multi Location Checkout

* Public checkout routes now support new syntax for multi location checkout; backwards compatibility maintained for old syntax.

* Proxy Username & Proxy Password fields deprecated; please use Proxy User authentication.

* Public service routes now return associated `service_line_item` objects in the response.
</Update>

<Update label="1.5.80">
  ## Improved Proxy Observability and Debugging

* Proxy error code returned under `x-byteful-status-code` header.

* Proxy request ID returned under `x-byteful-request-id` header.

* More informative proxy error codes.
</Update>
